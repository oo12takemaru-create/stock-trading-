📊 SBI証券 CSV インポート(履歴 / 保有)

SBI証券のCSVを自動判別して取り込みます:
・「実現損益詳細」→ 過去トレード(クローズ済)を一括登録
・「保有証券一覧」→ 現在の保有をOPENポジションとして登録
※ 重複(同じ銘柄/約定)は自動スキップ。保有の損切り/目標は仮値(取得−5%/+10%)で登録され、後から編集できます。

📋 SBI CSV の取得方法
  1. SBI証券にログイン
  2. 「口座管理」→「My資産」→「実現損益詳細」
  3. 期間を指定 → 「検索」
  4. 右上の「CSVダウンロード」をクリック
  5. ダウンロードした CSV(SHIFT-JIS / UTF-8 両対応)をこのボタンから取り込む
